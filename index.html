Синхронизация через ваш GitHub

Один файл прогресса лежит в вашем репозитории. Каждое устройство пишет в него и читает из него — и карта выглядит одинаково на компьютере и на айпаде. Ключ хранится отдельно на каждом устройстве и никогда не попадает внутрь файла прогресса.

Как в адресе: ivanov/svyatie90. Репозиторий может быть и приватным.
Fine-grained token: доступ только к этому репозиторию, право Contents: Read and write.
Как получить ключ — по шагам
  1. Создайте на GitHub репозиторий, куда положите эту карту. Можно приватный.
  2. GitHub → фото профиля → Settings → внизу слева Developer settings.
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. Repository access → Only select repositories → отметить этот репозиторий.
  5. Permissions → Repository permissions → Contents → Read and write.
  6. Создать, скопировать ключ и вставить сюда. Ключ показывается один раз.
  7. Нажать Отправить — в репозитории появится файл прогресса.
  8. На айпаде открыть ту же страницу, вписать те же поля и нажать Забрать.
Если репозиторий публичный, файл прогресса виден всем. Там только галочки, но имейте в виду.
